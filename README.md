# PartStamp

Partstamp is a tool for stamping revision marks on 3D print files (primarily).
Partstamp lets you setup a projection plane to stamp a 3d part on, marking 3d prints
with revision information for use in CI/CD!

## Usage

### CLI Mode (default)
```bash
cargo run
```

### GUI Mode
```bash
cargo run -- --gui
# or
cargo run -- -g
```

## Building

```bash
cargo build --release
```
